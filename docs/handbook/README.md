# Rewind Video: Clerk handbook

Welcome to the counter! This page has everything you need to run Rewind. Keep it by the register.

## Moving around

The tabs along the top are Rewind's five screens. Press a key to jump to one from anywhere:

| Key | Screen |
| --- | --- |
| **F1** | Checkout |
| **F2** | Return |
| **F3** | Ask the Clerk |
| **F4** | Intake |
| **F5** | Store Manager |

You can also click a tab, or press **Tab** until it has a dotted line around it, then press **Enter**.

- **Tab** moves to the next button or box.
- **Enter** presses the button with the dotted line around it.
- **Esc** means Cancel.

Checkout, Return and Ask the Clerk are still being built. This page will explain them when they're ready.

## Adding a movie

Press **F4** for Intake.

1. Type the title from the DVD case, then press **Enter**. Rewind looks it up on TMDB, a big movie website.
2. Lots of movies share a name, so find the right one by its poster and year. Press **↓** and **↑** to move through the list, or click one.
3. Press **Enter** to add it. Rewind shows its poster, its rating and who's in it. You don't need to close that: just type the next title and press **Enter**.

Can't find it? Type more of the title and search again. **Esc** closes the list.

## Scanning

Just scan. You don't need to click anything first: Rewind hears the scanner on every screen.

The bar along the bottom of the screen shows the last thing you scanned. Next to it, Rewind says how the scanner is doing:

- **Scanner ready:** all good.
- **Scanner missing:** check that the scanner's cable is plugged in. Rewind finds it again by itself in a few seconds.
- **Scanner busy:** another program is using the scanner. Tell the Store Manager.

## When a message pops up

Read it, then press **Enter** for OK or **Esc** for Cancel. The rest of Rewind waits until you answer.

If it says **"This program has performed an illegal operation"**, something went wrong inside Rewind. Press **Enter** and you'll be back on Checkout. Then tell the Store Manager what you were doing, so it can be fixed.

If it was Checkout itself that went wrong, Checkout stays closed and says **"Checkout closed after an error."** Press **F1** to open it again, or **F5** for the Store Manager.

If the message says Rewind **will be shut down**, press **Enter** and Rewind closes. Tell the Store Manager, who can start it again.

If a plain box says Rewind **can't start**, press **Enter**, then tell the Store Manager what it said. Rewind can't fix that one by itself.

If Rewind closes by itself, without a message, wait a moment. It starts again on its own.

## Closing up

When the store closes, press **F5**, click **Shut Down**, then press **Enter** for OK.
